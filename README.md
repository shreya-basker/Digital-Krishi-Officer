# 🌾 Krishi Mitra — Digital Krishi Officer

**Krishi Mitra** is an AI-powered farmer advisory web platform designed to provide **real-time, localized, and government-backed agricultural guidance** to farmers in their native language.

It aims to function as a **Digital Krishi Officer**—always available, context-aware, and scalable across regions.

---

## 🎯 Problem Statement

Farmers often struggle to access timely expert advice related to crop diseases, weather conditions, agricultural inputs, government schemes, and market prices. Existing helplines and agricultural officers are overburdened and cannot scale to meet individual farmer needs across diverse regions and languages.

---

## 💡 Solution Overview

Krishi Mitra provides a **single digital platform** where farmers can:

- Ask agriculture-related questions  
- Access government schemes and subsidies  
- Check mandi prices  
- Learn best practices via tutorials  
- Receive AI-powered recommendations  

The system is designed with **simplicity, accessibility, and regional relevance** at its core.

---

## 🧠 Key Features

- 🗣️ **Farmer Query System** – Ask crop, pest, soil, or weather-related questions  
- 📋 **Government Schemes Explorer** – Easy access to relevant agricultural schemes  
- 📊 **Mandi Prices** – View updated crop market prices  
- 🎓 **Farming Tutorials** – Learn best practices  
- 🧭 **Dashboard Interface** – Centralized access to services  
- 🌐 **Local-Language Friendly Design** – Malayalam-first vision

## ⚙️ How It Works

1. Farmer opens the platform via browser  
2. Navigates to the Query page  
3. Submits a farming-related question  
4. Query logic processes the request  
5. (Planned) AI engine generates context-aware responses
